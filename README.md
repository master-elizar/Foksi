# Foksi

Минималистичный планировщик событий, задач и заметок для Android с упором на умные
предварительные напоминания: записал один раз — приложение само поможет не забыть.

## Что внутри

- **Kotlin + Jetpack Compose + Material 3**, Navigation Compose, ViewModel, Coroutines/Flow.
- **Room** для локального хранения (события, напоминания, чек-листы, вложения, категории,
  запланированные уведомления), **DataStore** для настроек.
- **AlarmManager + WorkManager** для надёжной доставки напоминаний: точные будильники,
  восстановление после перезагрузки, реакция на смену времени и часового пояса.
- **App Widgets** трёх размеров (2×2, 4×2, 4×4) на классических RemoteViews с адаптацией
  под изменение размера.
- Русский и английский языки, светлая/тёмная тема и пять пастельных цветовых схем.
- Экспорт/импорт JSON и ICS, локальная резервная копия.
- Аккаунт не нужен, данные не покидают устройство.

## Структура

```
app/src/main/java/com/foksi/app/
├── core/            форматирование дат и обратных отсчётов
├── data/
│   ├── local/       Room: сущности, DAO, конвертеры, миграции
│   ├── repository/  репозитории и мапперы domain ⇄ entity
│   └── backup/      JSON/ICS экспорт-импорт
├── domain/
│   ├── model/       доменные модели
│   ├── logic/       планировщик напоминаний, повторы, тихие часы, группировка
│   └── usecase/     PlanInteractor — единая точка записи
├── notifications/   каналы, планировщик alarm'ов, ресиверы, экран будильника, snooze

├── ui/              темы, компоненты, экраны, ViewModel'и, навигация
└── di/              AppGraph — ручной service locator
```

## Система напоминаний

1. **Основные напоминания** — сколько угодно на событие, каждое со своим типом:
   обычное / важное / будильник, опционально «повторять, пока не подтверждено».
2. **Цепочка подготовки** — 14 дней → 7 → 3 → 1 день → 3 ч → 30 мин, любой этап отключается.
3. **Интервальные** — каждые N дней до события.
4. **Случайные** — N раз в неделю в разрешённом окне времени, детерминированно
   (одинаковые слоты при пересчёте), с минимальным интервалом между уведомлениями.
5. **Чек-лист** — отдельное напоминание, если до события мало времени, а пункты не закрыты.

Тихие часы, приоритет события и минимальный интервал применяются ко всем «мягким»
напоминаниям; точные напоминания и будильники никогда не отбрасываются молча — они
переносятся на ближайшее разрешённое время.

## Сборка

Для разработки нужны JDK 17 и Android SDK 35. Запустите Gradle Wrapper с задачами :app:testDebugUnitTest и :app:assembleDebug. GitHub Actions сохраняет отладочный APK в артефактах запуска.

Для сборки AAB задайте FOKSI_UPLOAD_STORE (абсолютный путь к закрытому хранилищу с алиасом upload) и FOKSI_UPLOAD_PASSWORD (пароль ключа и хранилища) в окружении процесса. Запустите :app:bundleRelease. Результат появится в app/build/outputs/bundle/release/.
